# 08. 近接領域との関係

HSSは、以下に挙げる理論、研究、論文を参照して構築されたものではありません。

また、HSSの初期概念、主要語彙、観測軸は、これらを参考にして設計したものでもありません。

HSSによる観測軸を形成した後、既存の専門領域と照合したところ、部分的に類似する問題意識や、接続可能な研究領域があることに気づきました。

この節は、HSSの出典や根拠を示すものではありません。


HSSの形成順序としては、まず創作、運用、組織、文化、AIとの対話を通じて、初期語彙と観測軸が形成されました。

その後、既存領域と照合し、近い問題意識を持つ領域をこの文書に整理しています。

このため、この文書で挙げる領域はHSSの出発点ではなく、形成後に読者が接続しやすくするための参照点として扱います。

ここでは、HSSと部分的に近い問題意識を持つ研究、理論、論文を紹介し、読者が既存の専門領域へ接続するための補助線として整理します。


## コアモジュールと近接領域の関係

HSSのコアモジュールは、「よくある話の流れ」を軽視するのではなく、複数領域で反復して現れる接続構造の最小パターンとして扱います。

この発想は、物語構造、記号論、社会システム論、文化記憶、文化進化、指標最適化、sensemaking、attention economy などの近接領域と部分的に接続します。

ただし、HSSはそれらを統合・代替・上位化するものではありません。

HSSで見るのは、特定領域の理論ではなく、文化、市場、組織、platform、評価制度、symbol循環にまたがって、何が積層し、何へ圧縮され、どこで再接続や再展開が起き、どこで固定化や再接続の細りが起きるかです。

## HSSに固有の構造的限界

HSSの強みは、文化、創作、市場、組織、platform、評価制度、symbol循環にまたがって、反復して見える接続構造を粗く観測できる点にあります。

一方で、その横断性は、HSSに固有の構造的限界にもなります。

- 単一のコアモジュールで読むため、並列・競合する複数の接続経路が同時に走る状況を粗くしやすい。
- symbol、処理形式、再接続経路を中心に見るため、感情、身体性、欲求、快・不快などの深い層は直接扱いにくい。
- 横断的に読むため、個別領域の専門理論ほど、制度、歴史、心理、経済、技術の詳細を精密には扱えない。
- 「よくある流れ」を最小コアモジュールとして扱うため、通常説明との差分を明示しないと、後付けの読み替えに見えやすい。
- 定量的な閾値よりも複数の兆候を組み合わせて観測するため、判定には観測者の裁量が残る。
- HSS語彙で読めること自体は、HSS観測が強いことを意味しない。処理形式への変換、再接続経路の変化、固定化、Blue residuals、揺り戻し欠損、目的関数の捕獲などの追加観測点が必要になる。

これらはHSSを否定するための欠陥ではなく、HSSを過剰適用しないための境界です。

HSSは、近接領域を置き換えるものではなく、接続構造の反復を粗く観測するための補助的な観測フレームとして扱います。

## 近接領域の個別メモ

以下の個別メモは、比較表に挙げたすべての領域を同じ粒度で詳述するものではありません。

現時点でHSSの読者が既存領域へ接続しやすい代表的な領域について、補助線として短く整理します。

比較表にあるが個別メモがない領域は、今後必要に応じて追加します。

### 記号論 / Semiotics

HSSでいう symbol は、記号論における sign、object、interpretant などの議論と部分的に近く見える場合があります。

sign、object、interpretant に近い循環を考えるうえで、記号論はHSSとの接続が比較的強い領域の一つです。

ただし、HSSは記号論を参照して構築されたものではなく、記号の意味論そのものを定義するものでもありません。

HSSで観測するのは、symbol がどの文脈、関係、積層history、ルーティングへ再接続できるかです。

### Goodhart's Law / 指標最適化

Goodhart's Law は、指標が目標化されると、その指標が本来の測定対象を保ちにくくなる問題として知られています。

HSSは Goodhart's Law を参照して構築されたものではありません。

HSSでいう圧縮symbol、KPI、評価指標、目的関数の捕獲は、指標が元の目的や価値への再接続経路を細らせる局面を観測する点で、特に近い問題意識を持ちます。

HSSでは、より上位の目的、問い、価値が指標へ圧縮される過程と、その後に元のルートへ戻る接続可能性がどのように狭まるかを観測します。

### Boundary Object / 境界対象

Boundary Object は、異なる共同体が異なる解釈を持ちながらも、協働のために共有できる object として語られることがあります。

Boundary Object は、伝票、文書、チケット、ラベル、KPI、source anchor などを、複数の社会的世界や処理文脈を横断する対象として読むときに有用です。

HSSは boundary object 論を参照して構築されたものではありません。

ただし、HSSで扱う source anchor、伝票、チケット、仕様書、business case、承認フォーム、KPI、ラベルなどは、複数の接続圏をまたぐ処理形式として観測できる場合があります。

HSSでは、それらが接続可能性を残すのか、処理形式だけを流通させるのか、再接続経路を太くするのか細らせるのかを観測します。

### Sensemaking / 組織的意味形成

Sensemaking は、曖昧な状況や経験が、組織や人々の中でどのように意味づけられるかを扱う領域として知られています。

Sensemaking は、組織的な意味形成を考えるうえで有用な接続点になります。

HSSは sensemaking 研究を参照して構築されたものではありません。

また、HSSは心理過程としての意味形成を定義しません。

HSSで観測するのは、どの symbol、記録、ラベル、処理形式が、どの文脈や接続経路へ戻れるかです。

### Affordance / 行為可能性・接続可能性

Affordance は、環境や対象が主体にどのような行為可能性を与えるかという問題意識と関係します。

Affordance は、対象、環境、受け手の間で生じる可能性を考える助けになります。

HSSは affordance 論を参照して構築されたものではありません。

ただし、HSSは対象単体の性質よりも、再接続可能な文脈とsymbolのルーティングに焦点を置きます。

HSSでは、物理的な行為可能性だけでなく、symbol、記録、伝票、KPI、表現、source anchor などが、どの文脈、記憶、組織処理、文化的再利用へ接続できるかを観測します。

### Self-Determination Theory / 自己決定理論

Self-Determination Theory は、autonomy、competence、relatedness などを中心に、動機づけを扱う心理学理論として知られています。

この接続は限定的な補助線です。

HSSは自己決定理論を参照して構築されたものではありません。

また、HSSは動機、欲求、自律、competence、relatedness、心理的欲求を定義しません。

ただし、自己決定、自律、自己責任、自己制御と呼ばれるものが、どの接続経路や処理形式へ配置されるかを観測する場合があるため、補助的に置いています。

## 注意

ここで挙げる領域は、HSSの根拠や出典ではありません。

また、HSSがこれらの理論を統合、代替、上位化するものでもありません。

HSSは、接続、圧縮、再接続、積層history、Shiwa、Blue residuals などを観測するための作業用モデルです。

この文書は、読者がHSSを既存の専門領域へ接続するための補助線として置きます。
