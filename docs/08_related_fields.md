# 08. 近接領域との関係

HSSは、以下に挙げる理論、研究、論文を参照して構築されたものではありません。

また、HSSの初期概念、主要語彙、観測軸は、これらを参考にして設計したものでもありません。

HSSによる観測軸を形成した後、既存の専門領域と照合したところ、部分的に類似する問題意識や、接続可能な研究領域があることに気づきました。

この節は、HSSの出典や根拠を示すものではありません。

ここでは、HSSと部分的に近い問題意識を持つ研究、理論、論文を紹介し、読者が既存の専門領域へ接続するための補助線として整理します。

## 1. 記号論 / Semiotics

HSSでいう symbol は、記号論における sign、object、interpretant などの議論と部分的に近く見える場合があります。

Charles Sanders Peirce による sign、object、interpretant の整理は、この近接領域を読むための代表的な参照点になりえます。

ただし、HSSは記号論を参照して構築されたものではなく、記号の意味論そのものを定義するものでもありません。

HSSで観測するのは、symbol がどの文脈、関係、積層history、ルーティングへ再接続できるかです。

## 2. Goodhart's Law / 指標最適化

Goodhart's Law は、指標が目標化されると、その指標が本来の測定対象を保ちにくくなる問題として知られています。

HSSは Goodhart's Law を参照して構築されたものではありません。

ただし、HSSでいう圧縮symbol、KPI、評価指標、目的関数の捕獲は、指標が元の目的や価値への再接続経路を細らせる局面を観測する点で、部分的に近い問題意識を持ちます。

HSSでは、より上位の目的、問い、価値が指標へ圧縮される過程と、その後に元のルートへ戻る接続可能性がどのように狭まるかを観測します。

## 3. Boundary Object / 境界対象

Boundary Object は、異なる共同体が異なる解釈を持ちながらも、協働のために共有できる object として語られることがあります。

Star and Griesemer による boundary object の議論は、この近接領域を読むための代表的な参照点になりえます。

HSSは boundary object 論を参照して構築されたものではありません。

ただし、HSSで扱う source anchor、伝票、チケット、仕様書、business case、承認フォーム、KPI、ラベルなどは、複数の接続圏をまたぐ処理形式として観測できる場合があります。

HSSでは、それらが接続可能性を残すのか、処理形式だけを流通させるのか、再接続経路を太くするのか細らせるのかを観測します。

## 4. Sensemaking / 組織的意味形成

Sensemaking は、曖昧な状況や経験が、組織や人々の中でどのように意味づけられるかを扱う領域として知られています。

Karl Weick による sensemaking の議論は、この近接領域を読むための代表的な参照点になりえます。

HSSは sensemaking 研究を参照して構築されたものではありません。

また、HSSは心理過程としての意味形成を定義しません。

HSSで観測するのは、どの symbol、記録、ラベル、処理形式が、どの文脈や接続経路へ戻れるかです。

## 5. Affordance / 行為可能性・接続可能性

Affordance は、環境や対象が主体にどのような行為可能性を与えるかという問題意識と関係します。

Gibson の affordance 論は、この近接領域を読むための代表的な参照点になりえます。

HSSは affordance 論を参照して構築されたものではありません。

ただし、HSSでいう接続可能性は、対象単体の性質ではなく、受け手、環境、文脈、積層historyとの関係から生じる点で、部分的に近い見方を持ちます。

HSSでは、物理的な行為可能性だけでなく、symbol、記録、伝票、KPI、表現、source anchor などが、どの文脈、記憶、組織処理、文化的再利用へ接続できるかを観測します。

## 6. Self-Determination Theory / 自己決定理論

Self-Determination Theory は、autonomy、competence、relatedness などを中心に、動機づけを扱う心理学理論として知られています。

Deci and Ryan による autonomy、competence、relatedness の整理は、この近接領域を読むための代表的な参照点になりえます。

HSSは自己決定理論を参照して構築されたものではありません。

また、HSSは欲求、動機、心理状態を定義しません。

ただし、自己決定、自律、自己責任、自己制御と呼ばれるものが、どの接続経路や処理形式へ配置されるかを観測する点では、部分的に接続可能な領域があります。
