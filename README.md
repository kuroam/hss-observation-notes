# 継続接続と再展開の循環モデル

## ー 短サイクル市場における文化形成と接続構造上の問題観測メモ（仮）ー

## HSS（High-speed Society Structure）

English working version: [README.en.md](README.en.md)

このリポジトリにおけるHSSは、High-speed Society Structure の略称です。
心理学上の High Sensation Seeking などの人格特性分類を指すものではありません。

HSSは、社会的な継続接続による文化や関係性の変化を、動的に観測するための構造メモです。
固定化された理論ではなく、接続構造を観測するためのPoC（接続構造観測OS）として扱います。

ここでいう「OS」は比喩です。

現時点のHSSは、完成した実行環境ではなく、観測語彙、観測テンプレート、事例レポート、反例・難例によって更新される構造観測フレームとして扱います。

観測の入力、処理手順、出力形式、更新ルールは、主に docs/07_observation_template.md と観測レポート群で暫定的に運用します。

## HSSは何をするものか

HSSそのものは、単一の接続モデルではありません。

HSSは、社会・市場・組織・platform・文化・symbolにおいて観測される「接続しているように見えるもの」を、接続元、接続先、媒介symbol、処理形式、痕跡、ルーティング、固定化、再接続可能性へ分解するための構造観測OSです。

目的は、真理を確定することではありません。

言われている接続、見えている接続、接続していると考えられている現象が、HSSの観測粒度で見て、どの接続構造として成立しているかを切り分けることです。

HSSによる分解結果は、成功 / 失敗ではなく、接続確認、接続未確認、接続先違い、処理形式への吸収、情報不足、対象外レイヤーとして扱います。

## このモデルの位置づけ

HSSは、既存の理論、研究、論文を参照して構築したモデルではありません。

HSSの初期概念、主要語彙、観測軸は、創作、運用、組織、文化、AIとの対話を通じて、独立に形成したオリジナルの観測モデルです。

ここでいうオリジナルとは、既存理論の上位性や代替性を主張する意味ではなく、既存理論を出発点として設計したものではないという意味です。

そのため、HSSは特定の学術理論の派生、応用、要約、統合を目的とするものではありません。

ただし、HSS形成後に既存の専門領域と照合すると、部分的に類似する問題意識や、接続可能な研究領域があることに気づきました。

それらはHSSの出典や根拠ではなく、読者が既存領域へ接続するための補助線として、[近接領域との関係](docs/08_related_fields.md) に整理します。

## HSSの5つの暫定claim

HSSは完成理論ではありませんが、現時点では次の暫定claimを置いて観測します。

- 短サイクル環境では、symbolが低トークン化・固定化されやすい場合がある。
- 固定化symbolは高速循環を助ける一方で、再解釈可能性や再接続経路を狭める場合がある。
- 文化形成や関係形成には、固定化だけでなく、Blue residuals、接続可能なズレ、積層historyが必要になる場合がある。
- 外部指標や処理形式が目的化すると、元の価値や文脈への再接続経路が細る場合がある。
- HSSは人間本質を定義するものではなく、symbol、処理形式、接続経路、固定化、再接続、再展開、積層historyの変化を粗く観測するためのPoCである。

これらは確定命題ではなく、今後の観測によって強まる場合も、弱まる場合もあります。

## 概要

HSSは、文化・関係性・創作・市場・symbolなどに見られる、
「継続接続」と「再展開」の構造を観測するためのPoC（構造観測メモ）です。

現時点では、以下のような要素を、主にL1〜L6の接続構造として整理します。

- 継続接続
- 再接続
- 再展開
- 固定化
- 積層的な関係形成

L1〜L3は、現時点ではHSSの前提層またはブラックボックス層として扱います。

READMEでは、L1〜L3を無理に定義せず、L4〜L6以降の観測で見え始めている接続構造を中心に整理します。

これは、モデルを未完成のまま放置するためではなく、現時点で過剰に定義して真理化することを避けるためです。

L1〜L3は、人間本質や脳生理を定義する層ではありません。

HSSでは、symbolや出来事が場に触れ、反応や痕跡として残り、処理形式へルーティングされるまでの前段観測層として仮置きします。

- L1: 接触層
  - symbol、出来事、言葉、映像、音、数値、制度、他者の反応などが、受け手や場に触れる層。
- L2: 反応・痕跡層
  - 接触したものが、違和感、記憶、反応、クリック、保存、会話、気になる感じ、処理負荷などの痕跡として残る層。
- L3: 処理・ルーティング層
  - 残った痕跡や反応が、KPI、評価制度、フィード、ランキング、伝票、指数、株価、再生数、承認、役割などの処理形式へ振り分けられる層。

L4〜L6では、L1〜L3で生じた接触、反応、痕跡、処理形式が、継続接続、再接続、再展開、固定化、積層historyとして観測可能になるかを扱います。

これは暫定的な観測上の置き方であり、完全な層定義ではありません。

HSSは、以下を定義するものではありません。

- 人格本質
- 精神本質
- AI意識論

また、「すべてを説明する完成理論」を目的としていません。

あくまで、複数領域で構造的に辻褄が合うかを観測するためのPoC（Proof of Concept）として扱います。

HSSは、暫定的な観測メモであり、完成理論・教義・人間本質論・人格類型論としては扱いません。

## 当初仮説

HSSの出発点には、以下の仮説があります。

> 短サイクル市場における最適化（極）は、文化形成や積層的な関係形成を阻害する可能性がある。

本モデルでは、次のような構造同士の関係を観測対象とします。

- 低トークン
- 高再帰
- 固定化symbol循環
- 文化形成
- 深み
- 継続接続
- 積層history

## HSSの現在地

現時点では、「接続構造と積層history」によって、以下のような対象が構造として辻褄が合い始めているかを観測する段階です。

- 文化
- 創作
- Buzz
- symbol
- 深み
- 関係性

ここでの整理は、確定ではなく、今後の観測によって更新される前提です。

今後は、HSSで構造が見えた事例だけでなく、HSS語彙では差分が出なかった事例や、観測が弱かった事例も、更新材料として扱います。

## 重要方針

HSSでは、以下を重視します。

- PoC保持
- Layer分離
- 真理化回避
- Blue residuals維持
- 接続可能領域維持
- 理力（つっこみ）

理力（つっこみ）は、HSSを真理化・教義化しないための自己批判的な確認力を指します。
観測結果が強く見えたときほど、反例、ズレ、過剰解釈、説明しすぎを確認するための補助姿勢として扱います。
